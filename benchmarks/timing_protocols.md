# 测量协议（全部实测数字的共同纪律）

1. **热身遍**：冷启动税实测 17x（82 -> 4.8 ms/字）——任何计时前先跑 1-3 遍不计数；
2. **torch.cuda.synchronize() 再掐表**：CUDA 异步，只递交就返回，不同步量到的是递交时间；
3. **中位数/多遍均值**抗毛刺；计时格间 torch.cuda.empty_cache() 清场（单变量纪律）；
4. **cache 每场新建**、入口 ids 防御性处理——两次运行可比；
5. 推理一律 @torch.no_grad()：实测时间税 ~25%，显存税足以 OOM（14.7GB/16GB 实录）；
6. 每组数字记录：模型/精度/prompt 长度/生成数/机器（5070 Ti）。
